# RoseStone Expense Tracker

A modern, responsive web application for tracking personal and business expenses with budget management and Google Drive integration.

## 🌟 Features

- **Dual Expense Tracking**: Separate personal and business expense management
- **Budget Management**: Set total monthly budgets and distribute across categories
- **Category Management**: Customize expense categories with icons and colors
- **Visual Analytics**: Pie charts and spending breakdowns
- **Google Drive Integration**: Sync data with Google Sheets (demo mode)
- **Dark/Light Mode**: Toggle between themes
- **Responsive Design**: Works on desktop, tablet, and mobile devices

## 🛠️ Local Development

### Prerequisites
- Node.js (version 14 or higher)
- npm or yarn

### Installation

1. Clone the repository:
```bash
git clone https://github.com/yourusername/rose-stone-expense-tracker.git
cd rose-stone-expense-tracker
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm start
```

4. Open [http://localhost:3000](http://localhost:3000) to view it in the browser.

### Building for Production

```bash
npm run build
```

This builds the app for production to the `build` folder.

## 📱 Usage

1. **Add Expenses**: Use the form at the top to quickly add new expenses
2. **Set Budgets**: Go to the Budgets tab to set monthly budgets
3. **Manage Categories**: Customize expense categories in Settings
4. **Track Spending**: View spending breakdowns and budget usage
5. **Export Data**: Use Google Drive integration to sync data

## 🎨 Customization

- **Categories**: Add, edit, or delete expense categories
- **Themes**: Toggle between dark and light modes
- **Budgets**: Set monthly budgets and distribute across categories
- **Google Drive**: Configure cloud sync (demo mode)
